## 開発予定機能（最低限の電卓機能）

本プロジェクトでは、まず「四則演算が正しく行える電卓」を最低到達点とし、
段階的に機能を追加する方針とします。

---

### ✅ フェーズ1：基本動作（必須）

- [ ] 数値の入力（整数・小数）
- [ ] 四則演算
  - [ ] 加算（+）
  - [ ] 減算（-）
  - [ ] 乗算（*）
  - [ ] 除算（/）
- [ ] 計算結果の表示
- [ ] 連続計算（例：`2 + 3 * 4`）
- [ ] クリア機能（全消去 / 入力中消去）

---

### ✅ フェーズ2：入力・操作の安定化（最低限推奨）

- [ ] 不正な入力の防止
  - [ ] 数字以外の入力チェック
  - [ ] 演算子の連続入力防止
- [ ] 0 での除算エラー処理
- [ ] 小数点の多重入力防止
- [ ] 計算途中状態の管理

---

### ✅ フェーズ3：内部処理の品質向上

- [ ] 演算ロジックと UI の分離
- [ ] 演算処理を関数またはクラスに分離
- [ ] 計算処理の単体テスト
- [ ] 浮動小数点誤差への配慮（必要に応じて）

---

### ⏳ フェーズ4：基本拡張（余裕があれば）

- [ ] 符号反転（±）
- [ ] パーセント計算（%）
- [ ] 計算履歴の保持
- [ ] 直前の計算結果の再利用

---

### ⏳ フェーズ5：UI・操作性（任意）

- [ ] キーボード入力対応
- [ ] ボタン入力対応（GUIの場合）
- [ ] 表示桁数制限
- [ ] エラーメッセージの明確化

---

### 🎯 最低到達目標

- 四則演算が正しく動作すること
- 想定外入力でアプリがクラッシュしないこと
- ロジックと表示処理が分離されていること

---

### 📌 開発方針メモ

- まずは **正確に動くこと** を最優先とする
- 拡張は後回しにし、最小構成で完成させる
- 機能追加時は既存機能を壊さないこと
